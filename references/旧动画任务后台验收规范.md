# 旧动画任务后台验收规范

仅供已经存在的旧动画任务恢复，或明确指定的旧格式详细检查。不得用于新任务；新动画采用《PPT动画轻量规范》，可编辑修订采用《可编辑后续一体化规范》。新任务不能通过旧命令创建。以下保留旧格式的解析与审阅合同，不改变全程后台要求。

当前解析器仅接受完整顶层对象0.2—1.2秒淡入，触发为`click`或`with_previous`；同组同步、每组明确单击。已有相同完整对象淡入可以保留或明确替换。对时间树逐节点及结构校验，未知条件、自动开始、after_previous、退出/运动路径、分段文字、复杂交互、音视频、OLE等不近似，不进入完成状态；主控可在授权边界内将教学方案调整为支持的淡入或静态，否则列明阻断页。

检查范围是初始及每次点击完成状态、语义顺序和原包保真。没有验证动画过渡每一帧，没有实际测试任意版本PowerPoint/WPS播放兼容，不能声称“目标播放器实际放映通过”或“所有效果保证完全一致”。环境具备时，在声明支持范围内所有下列门槛必须通过，不为了全程后台删掉视觉QA；缺环境的检查按后文记录未验证，文件差异和时间轴结构核验始终执行：

1. 实际原稿后台全页预览审阅；图中文字与底图残留必须检查，XML不足以覆盖。
2. 按当前教学用途识别题目、待揭示答案、解释与插画。每页plan设`content_roles_reviewed=true`及`visibility_rules`，例如`{"shape_id":7,"role":"answer","reveal_click":2,"reason":"先独立判断，再揭示答案"}`。`answer`专指需要在独立判断或讨论后揭示的答案，不能初始可见；`reveal_click=0`可用于题干/比较材料（`prompt`）、已经作为学习材料提供的示范或复盘说明（`explanation`）及适用插画。角色和时机须有真实教学理由，并与`sequence_evidence`和`teaching_units`一致；不能为绕过泄题检查把待答任务的答案改标成材料，也不强迫已知示范增加无用动画。没有相关对象时规则为空，但主控仍需确认该页语义及图片里没有需要隐藏的答案。
3. `apply-teaching-animation`执行后核验完整包差异；读取成品时间树核对目标、触发、时长、分组和可见性规则。按每页sequence_evidence与teaching_units另核对独立预期顺序、必要参照、实际目标覆盖及同单元同时完成，不能只拿effects与其写入结果互相印证。文件变化或不支持行为即失败。
4. `export-animation-states`导出每页初始、全部点击完成状态；每个状态有实际图片、可见/隐藏对象、输入/输出/计划/图片指纹。空白截图、缺失状态和旧证据均不能验收。
5. 主控逐张审阅全部状态，检查题目与答案是否错序、选项图片内的勾叉/颜色/边角文字是否提前泄题、隐藏对象后是否露出旧线/旧字/阴影、必要题干和对比依据是否还在、组内图文是否同步、字体是否缺字/回退、断行和遮挡、最终全部内容是否恢复。答案框隐藏不等于整页没有答案；最终恢复也不等于初态和中间状态合格。沿用answer_leakage_observation、background_residue_observation、visibility_observation写具体内容，不新增平行验收表；有问题不能填pass。
6. 用`record-animation-background-review`登记下面契约；runtime只核对完整性、指纹和声明范围，不自动生成pass。若启用字体检查，同一份全部状态审阅包含全页字体/排版，额外生成独立font_review证据，无需再打开应用。

## 后台审阅契约

```json
{
  "method":"background_click_states",
  "controller_reviewed":true,
  "input_sha256":"sha256:...",
  "output_sha256":"sha256:...",
  "plan_sha256":"sha256:...",
  "manifest_sha256":"sha256:...",
  "unresolved_issues":[],
  "states":[{
    "page":1,"step":0,"pass":true,"image_sha256":"sha256:...",
    "visibility_observation":"写实际可见和隐藏内容",
    "answer_leakage_observation":"写题目、答案及底图文字检查结果",
    "background_residue_observation":"写隐藏对象后背景是否完整",
    "font_observation":"写中文、字体、粗细及原字体保留检查结果",
    "layout_observation":"写断行、遮挡和完整显示检查结果",
    "original_comparison_observation":"新字体清单的每页最终状态必填：实际对照原版同页及输入预览的文字、字形、粗细、断行与版式"
  }]
}
```

所有page/step恰好覆盖background_manifest的全部状态，不能只登记初始和最终。每页点击数包含保留的已有动画。输入/输出/plan/manifest/状态图任意变化使验收失效。状态为`waiting_background_review`直到全部检查通过，再`completed`；完成摘要写“后台点击状态验收通过”，不伪造实际放映事实。旧放映验收及旧状态不自动迁移。

额外的原生动画视频只能补充运动过程研究证据，不能替代上述全部点击状态和指纹门槛，也不能据CreateVideo成功设置actual_slideshow_accepted。说明视频来自原时间树、研究新增或研究重排，记录输入/输出/计划/视频指纹、Office版本/build、实际帧率尺寸、点击排时来源及人工查看的具体帧。导出器自动安排点击的绝对时间不是教师真实点击间隔；研究重排不能冒称原稿过程。未查看全部帧时明确为抽样过程观察；未测返回/重置、WPS或课堂效果时不得称已验收。

原动画识别读取完整行为和结构，不凭filter含fade/wipe判断为支持效果：复合展开可能含fade，位移/缩放可能使用p:anim而没有p:animMotion。现有严格解析器不因研究中能导出视频而放宽；无合格效果可用时保留静态或列实际阻断。

文字保真与呈现检查分开：纯动画和旧窄范围字体任务保留原字、数字、标点、空格与显式换行检查。已授权文字优化允许计划内断行/明确中文排版空格与来源绑定的原稿还原，其余字词、数字、单位、答案及有意义标点仍保护；未调整页保持最终画面对照，优化页全部状态实际检查正文/字形/层级/断行/溢出/留白，写text_quality_observation。原版、当前输入、计划和证据指纹仍核对。正文待办只影响相关页，全稿不能冒称通过；详细合同见《可编辑文字优化规范》。


## 旧任务缺环境恢复

成品仍做原包差异、完整时间轴、触发/组/可见性规则检查；未解决的实际结构或内容问题仍阻断。环境缺失的动画状态为`verification_skipped`、`background_accepted=false`，只完成文件制作交付，不能称后台视觉、字形或播放器验收通过。基础项目保留原完成事实，独立动画项目可收口文件任务。环境恢复后先导出并实际审阅内部原稿快照的预览，再重新登记当前计划、执行和导出状态，完整审阅；本轮更新当前PPT并保留修改前快照，不递增成品版本，旧缺环境记录不冒充已验证。执行失败、缺页、不支持效果和已发现问题不得用缺环境规则跳过。
