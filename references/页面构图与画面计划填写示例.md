# 页面构图与画面计划填写示例

从[内容具体化与页组编排范例](内容具体化与页组编排范例.md)按当前困难选读，不要求逐例使用。以下是重新整理的假设教学与填写示意，不是项目批准稿、真实个案或效果证明；其中媒介、配色、位置、项目数量与时间只属于对应示意，不成为其他项目默认值。

| 当前困难 | 选读 |
| --- | --- |
| 总览有办法却不容易按问题选择 | [卡点与做法对应](#卡点与做法对应) |
| 说法完整但图不解释，或图面状态与条件冲突 | [完整话语与物品状态](#完整话语与物品状态) |
| 人物大图挤掉任务，或前后页没有保留同一产出 | [口述任务与后页反馈](#口述任务与后页反馈) |
| 反馈文字较多，需要同时保留检查、示例和边界 | [较密反馈页](#较密反馈页) |

## 读用边界与字段承接

每例先确定要让观众理解什么，再决定信息关系和主辅区。`content`代码块是现有`content.json`中的一个页面片段；`brief`代码块是现有`slide_prompt_briefs.json`中的对应片段，省略未变化字段，不是新增数据结构。示例文字需要采用时，先纳入本项目批准正文，再同步派生规划与brief，不能直接给旧图补字。

`message_goal`说明目标，`visual_anchor`定位对象或关系，`visual_composition`写分区和读序，`density_budget`写容量取舍，`acceptance_criteria`写可检查结果。决定成图的有效安排还须进入`image_prompt_plan.visual/layout`；媒介与色彩进入`style`，高风险错误进入`constraints`。只写在密度字段或报告里不会自动成为最终请求。

以下`image_prompt_plan`均为**登记前草稿**，没有`version`与`basis_hash`，不能直接当完整生产请求。实际使用时先协调本项目正文、一致性、风格及禁用项，再按[提示词建设规范](提示词建设规范.md#查看来源与登记计划)读取当前来源并登记，由现有程序取得真实摘要、补齐版本与组件。没有真实成图时只能核字段、文字和规划，不填成图QA或授课效果通过。图示中的用途名称不自动成为可见标签。

## 卡点与做法对应

**适用：** 高中学习方法的总览用于按困难选择做法。若本页只预告后文，清楚的并列列表也可保留。

先从本课材料找到四个具体困难，再为每个困难选择相容的办法；这不是人人依次走的四步。示意前页已让学生保留自己的一个卡点，后文再展开具体示范和尝试。

`content`页片段：

```json
{
  "slide_index": 7,
  "page_type": "content",
  "title": "四个学习动作，对应四种卡点",
  "purpose": "让学生按具体困难选择后续要尝试的办法",
  "final_visible_text": [
    "四个学习动作，对应四种卡点",
    "遇到的卡点",
    "可尝试的做法",
    "材料没到位：开课还在找资料。",
    "课前准备：资料先到位，带着一个问题进入课堂。",
    "笔记抄满了：说不出为什么。",
    "记录思路：留下条件、理由和疑问。",
    "一处没听懂：后面也跟丢了。",
    "处理卡点：判断现在问，还是标记后补。",
    "一直在点头：独立做又不会。",
    "主动加工：先判断，再解释，再验证。"
  ]
}
```

`brief`页片段：

```json

  "layout_family": "comparison_grid",

  "visual_composition": "标题下两列四行，问题列较短、方法列较宽；各行共用对齐基准，不以向下箭头连接。",
```

教师可以在原总览时段说：“回看你刚才保留的那一处卡点，哪一行更接近？说出依据即可。”这一次指认替代泛读，不另加整份计划。后续示范仍需给真实可用的题目或材料，不能把总览当作方法已经学会。目录若只写“课中”，却含课前准备，应同步调整命名范围，不自动加一个模块。

## 完整话语与物品状态

**适用：** 面向成人的假设沟通示范，核心是核对当前任务信息，不是证明催促必然造成某种心理或结果。

`content`页片段：

```json
{
  "slide_index": 11,
  "page_type": "content",
  "title": "示范：把“快整理”变成看得见的任务",
  "purpose": "比较提醒中是否提供了需要核对的任务信息",
  "final_visible_text": [
    "示范：把“快整理”变成看得见的任务",
    "假设情境：明天外出，需要水杯、纸巾和遮阳帽。孩子只把水杯放进小包。",
    "笼统提醒：“怎么还没好？快一点！”",
    "先核对：孩子知道还需要带什么吗？",
    "改说：“我们要带这三样。你已经放了水杯，还差哪两样？”",
    "用眼前实物提示任务，把找出遗漏留给孩子。"
  ]
}
```

`brief`页片段：

```json
{
  "slide_index": 11,
  "page_role": "content",
  "message_goal": "看清改说补了什么任务信息，以及孩子仍可以自己判断什么。",
  "layout_family": "case_walkthrough",
  "visual_anchor": "小包中只有水杯，纸巾和帽子仍在桌上。",
  "visual_composition": "左侧宽阅读区依次呈现情境、原提醒、核对和完整改说；右侧较小物品场景说明未完成状态，底部收束。",
  "density_budget": "保护完整话语的阅读宽度；人物和背景先缩减，不将长句拆进同高窄卡。物品不可缩成无法辨认的摆件。",
  "acceptance_criteria": [
    "六段完整，原提醒与改说的比较条件相同。",
    "水杯在包中，纸巾和帽子在包外；成人指物，没有全部代装。",
    "没有根据表情宣布孩子理解、配合或变自律。"
  ],
  "image_prompt_plan": {
    "visual": [
      "右侧同一半开绿色小包中仅有水杯，桌面纸巾和帽子清楚可辨；成人以手势提示物品，孩子看向物品，保留未完成状态。",
      "左侧为主要阅读区，完整话语连续展开，人物与纸艺装饰避让文字。"
    ],
    "style": [
      "本示意采用温暖专业的立体剪纸与压纹纸雕：奶油浅底、深青绿标题、深灰正文，橙色少量强调；暖光和薄投影，纸纹不穿字。",
      "中文为清楚平面的黑体，标题加粗；成人和幼儿自然比例，家庭情境明确为示意，不冒充活动照片。"
    ],
    "layout": [
      "第1段在左上作主标题，最多两行；标题下留出正文空隙。",
      "左侧第2段先交代情境，第3、4、5段顺序同一左基线，长句按语义换行；第6段在底部独立收束。",
      "右侧场景不得挤窄完整改说句，帽子和纸巾不裁出页面；段落开头的重点与普通正文形成字重层级。"
    ],
    "constraints": [
      "只用给定六段，不在物品上临时加标签或额外话语。",
      "不把所有物品预先装好，不将提示手势画成成人代装；不添加已发生的心理或成功结果。"
    ],
    "text_roles": {"title": 0}
  }
}
```

自然解释可说：“这里增加的不是一句鼓励，而是能核对的任务信息。水杯已经放了，另外两样还在眼前。”随后问改说增加了什么信息、哪一步仍留给孩子。若只回答“语气温柔”，可追问：“哪一句让人知道还要找什么？”不从孩子的表情推断原因，也不把这句话当成所有卡点的标准答案。

## 口述任务与后页反馈

**适用：** 小学短时小组讨论，产出是一句方案。页面要能开始操作，纸笔可选，不强改为填写表格或现场制作。

`content`页片段，含现有`teaching_intent`填写：

```json
{
  "slide_index": 20,
  "page_type": "activity",
  "title": "设计我们的热闹年",
  "purpose": "围绕参与者、材料与安全形成一个口头方案",
  "final_visible_text": [
    "设计我们的热闹年",
    "小组选择一项庆祝活动。",
    "说清：和谁做？需要什么？怎样注意安全？",
    "用一句话介绍给全班。"
  ],
  "teaching_intent": {
    "learning_goal": "形成能说明参与者、材料与安全考虑的选择，并接受一次具体修订。",
    "participant_task": "小组选一项活动，围绕三问口述一句；下一页检查原句。",
    "teacher_guidance": "示意本页3.5分钟、后页1.5分钟；纸笔可选，超时减少展示，保留口头修改。",
    "expected_output": "一句活动方案及后页修改过的一处具体内容。",
    "understanding_evidence": "三问均有回应，修改与安全或参与便利有关。",
    "reveals": []
  }
}
```

`brief`页片段：

```json
{

  "page_role": "activity",
  "message_goal": "从三问形成一句方案，为后页检查保留同一产出。",

  "visual_anchor": "三问是主阅读对象，完成方式紧接任务。",
  "visual_composition": "标题下给选择入口，中部宽主区按三个问句分组，下方紧接口述完成要求；小组场景收在右下作辅助。",
  "density_budget": "先保证三问和完成方式可读，陪衬人物与灯笼为任务让位；不加字段、表格或示例答案，避免把口述任务画成必须填表。",
  "acceptance_criteria": [
    "四段原文完整，三个问句易定位；人物不抢占任务空间。",
    "参与者知道在哪里作答，后页检查和修改的是同一句方案。",
    "独立尝试前不提前公布后页反馈，材料与原时段可用。"
  ],
  "image_prompt_plan": {
    "visual": [
      "中部主要区域承载三问，右下仅保留小幅小组商量的情境，不预填学生方案。",
      "第3段的三个现有问句按位置分组，不新增小标题；第4段紧接任务区说明完成方式。"
    ],
    "style": [
      "本示意采用传统中国年画手绘，米白纸底、深朱红标题、深棕正文，暖金少量装饰；冬日节庆氛围，纸纹避开文字。",
      "标题端正有力，正文平面清楚，段间留白；人物、梅花和灯笼为辅助，不占三问的主区。"
    ],
    "layout": [
      "第1段左上作主标题；第2段为选择入口；第3段获得主要阅读宽度，三个问句按语义换行；第4段在任务下方同起点排出。",
      "四段保留主次和段间空隙，辅助场景不跨入文字区，不用缩小正文容纳更多人物。"
    ],
    "constraints": [
      "正文仅给定四段，不临时添加时段、编号、字段、品牌或装饰字。",
      "任务是口头讨论，不画儿童操作爆竹、刀剪或开火，不预画真实成果与成功反馈。"
    ],
    "text_roles": {"title": 0}
  }

```

后页仍以本课同一句方案为对象。其`final_visible_text`示意为：

```json
[
  "让计划更安全",
  "听一听：活动是否安全、家人是否方便参加？",
  "补充或修改一个细节。",
  "活动因人而异，安全始终放在前面。"
]
```

在现有配套字段中分别填写，以下是备课示意，不是现场记录：

| 字段 | 具体填写 |
| --- | --- |
| `script`（任务页） | “先选一项活动，围绕屏幕上的三问，把它说成一句话。现在先和同组的人试着说，纸笔可选。” |
| `teacher_notes`（任务页） | 本例3.5分钟内安排指令、讨论和少量展示；材料为屏幕及口述，无需外部视频或现场操作用品。 |
| `response_branches`（任务页） | 备课预想：可能只说“剪窗花”。可接：“和谁做、需要什么、怎样注意安全，还缺哪一处？”无人回应时带读一个屏幕问题，给小组继续思考的时间，不宣布已完成。 |
| `script`（反馈页） | “听完建议，回到你们原来那句话，只改一个更具体的细节。说出改了哪里。” |
| `teacher_notes`（反馈页） | 本例1.5分钟内检查、修改和收束；超时减少公开展示，不取消各组修改，也不叠加新的活动。 |
| `response_branches`（反馈页） | 备课预想：可能只说“更好玩”。可追问：“这处改动让谁更方便参加，或解决了哪一个安全考虑？”收束后接本课已有主题回顾。 |

时间来自本例任务规模，不迁移为其他活动统一时长。教师可以直接承接这些话，但须依当前锁稿、受众和材料改写；正式配套仍经过原有审阅。

## 较密反馈页

**适用：** 需要同时保留核对依据、完整可说的示例和开放结果边界。正文多不自动判失败，先看层级、对应与实际可读性。

**前置材料：** 前页已经明示另一个假设任务：明天活动改在室内，不再带帽子，改带外套；孩子已收好物品，不愿重新整理。成人先拟一句回应，再来本页检查。不能将本页直接接在上面的外出示范之后而省略条件变化和尝试。

`content`页片段：

```json
{
  "slide_index": 14,
  "page_type": "content",
  "title": "回到刚才的回应，检查三件事",
  "purpose": "根据同一新情境核查回应，接受有依据的不同说法",
  "final_visible_text": [
    "回到刚才的回应，检查三件事",
    "有没有先弄清：孩子是否知道活动变了？",
    "有没有承认：已经整理好的努力，也可能让他不愿重来？",
    "有没有留下一步：一起确认要换的物品，让孩子选择先取帽子还是先找外套？",
    "一种可尝试的说法：“你已经装好了。明天改在室内，我们一起看看要换什么，你想先做哪一步？”",
    "若仍不愿意，先暂停、再商量；这不是唯一答案。"
  ]
}
```

`brief`页片段：

```json
{
  "slide_index": 14,
  "page_role": "content",
  "message_goal": "按条件核查并修改原回应，保留不是唯一答案的边界。",
  "layout_family": "case_walkthrough",
  "visual_anchor": "三个核对问题、完整说法与结果边界的连续读序。",
  "visual_composition": "左侧宽主区自上而下排三项核对，下面用独立浅底区容纳完整说法，最后单独排边界；右侧小包和人物仅作回指。",
  "density_budget": "先保护核对句、完整示例和边界，人物缩到辅助位置；长句自然换行，不删条件或压成难辨小字，仍不足时回规划调整跨页。",
  "acceptance_criteria": [
    "三个核对问题、完整示例和边界分别可找到，句子没有截断。",
```

## 同套固定项与功能变化

假设一个节庆项目已选择年画手绘：米白阅读底、深朱红左上标题、深棕正文、少量暖金装饰。标题锚点、字重层级与版心由本项目`PPT一致性.md`确定；媒介、笔触、光影与配色由`图片风格.md`确定。以下是这一个项目的内页延展示意，不是默认画风。

| 功能 | 当前构图与读序 | 容量变化时先处理什么 |
| --- | --- | --- |
| 目录 | 同级短语与必要说明纵向对齐，场景靠边辅助 | 先减少旁侧装饰，长说明按语义换行；不挤小某一条来凑齐宽度 |
| 操作过程 | 按实际顺序把文字与对应动作放近，需要看动作部位时用局部图 | 保留关键对象和状态参照，压缩泛场景；不让每步都只画人物捧成品 |
| 口述任务 | 入口、核心问题和完成方式形成主读序，小组场景从属 | 优先给任务区宽度，减少陪衬；不因前页是过程就强加箭头或改成表单 |

连续尝试与反馈可以保持共同骨架，变化须能由信息用途解释。把封面构图重复到每页、每隔几页强制换版，或按插画和卡片数量评分，均不能代替上述判断。知识赏读、比较、记录等其他任务使用自己的内容关系；示例不要求每套凑齐这些页型。
