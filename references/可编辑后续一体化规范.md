# 可编辑优化与教学动画 · 1.3.40

用户在一次请求中授权Canva修订、PPTX优化和动画后，连续完成下列流程，不再要求手动下载、再次提供同一设计链接或逐页确认。只请求Canva、文字、字体或纯动画时保持窄范围，不自动扩大。基础三步、人工PDF转PPTX及用户手动Magic Layers保持。

## 1. Canva保存与自动导出下载

先按《Canva辅助编辑任务规范》《Canva文字校对与精准修复规范》完成实际工具支持的修订、保存和回读。复用当前会话/项目已确认设计链接；多候选无法确定才问。Codex/WorkBuddy按既有工具路线；用户明确指定Canva MCP时继续MCP，不自动回退其他连接器或浏览器。不能从本地脚本直接调用宿主连接器，也不声称脚本已自动运行Magic Layers。

确认本批保存终态后，用当前连接器get-design取得实际design_id、标题和页数，再get-export-formats检查pptx支持，export-design导出全部页。下载只使用工具实际返回的临时URL，不猜地址；URL失效重新导出，未知结果先核对。导出并非重新从PDF生成PPT，不能凭pptx格式认定全部对象可编辑。

调用`download-canva-pptx --run-dir <项目> --task-id <Canva任务> --design-id <实际ID> --expected-pages <实际页数>`，将临时URL通过stdin传入；不放命令行参数、不写URL文件或日志。脚本只下载HTTPS Canva导出，检查ZIP与实际页数，按指纹保存到`_state/工具任务/canva/<task>/downloads/`并生成不含签名URL的download_manifest.json。来源、失败和是否已下载如实记录，不把导出成功冒作下载成功。

随后`prepare-editable-input --run-dir <项目> --source <下载原稿> --target <已有交付主题目录>/<主题>.pptx`放置工作文件。开始优化前同时检查工作文件名和最终`<主题>_可编辑动画版.pptx`。工作文件已有时拒绝覆盖；最终成品如可通过本项目已应用轻量任务、当前指纹及文件核验确认，则保存内部原稿快照并登记归档后放置新工作文件；不明文件及已变更旧稿提前拒绝，文件保持。中断按准备记录恢复，不以mtime猜版本。独立项目仍放PPT输出/<中文项目名>/，不把下载目录或Skill根作为项目。

## 2. 保留本地文字、字体与轻微排版修订

授权范围、正文保护、原稿疑误、相近常见非会员字体、整句/完整标题及跨框修复、显示映射和Canva字体交接全部沿用《可编辑文字优化规范》与《阶段5PPT教学动画规范》。新的`editable`入口执行原有修复合同，不写动画，也不把旧动画计划混入新动画步骤。

已有项目使用原状态；独立PPTX先`init --animation-only`。操作顺序：

```bash
python .skill/scripts/pptctl.py editable inspect --run-dir <项目> --input-pptx <工作PPTX> --evidence <本次真实原话> --optimize-text
python .skill/scripts/pptctl.py editable previews --run-dir <项目>
python .skill/scripts/pptctl.py editable plan --run-dir <项目> --file <修订计划JSON>
python .skill/scripts/pptctl.py editable apply --run-dir <项目>
python .skill/scripts/pptctl.py editable previews-output --run-dir <项目>
python .skill/scripts/pptctl.py editable review --run-dir <项目> --file <实际结果审阅JSON>
```

仅字体任务使用--repair-fonts或--match-reference-fonts，不附--optimize-text。无本地修订需求时可直接动画，不为纯动画初始化主阶段或渲染全稿。

修订计划包含input_sha256、controller_reviewed、preview_review_evidence、font_review_evidence、pages（每页page/font_observation）、font_repairs、text_optimizations、font_handoff_resolutions、pending_text_issues。字体和文字清单沿用原详细字段、字体安装/字形覆盖、视觉依据和来源合同。每个对象的修复不能重复覆盖；没有原稿依据不改正文；原稿疑误单列。受影响正文待办页保持输入原样，后续动画也排除该页。

实际预览和结果复核保留。review含controller_reviewed=true、input_sha256、output_sha256、plan_sha256、manifest_sha256、unresolved_issues=[]和pages；每页含page/pass/image_sha256及实际font_observation、layout_observation、text_quality_observation、original_comparison_observation。结果页覆盖全部页面，不用XML或计划文字假称看图。保存的Canva修订不能代替导出后字体检查。`editable previews`确认缺环境后自动记录verification_skipped、缺项及指纹，保留原文件所有字节，延后文字字体排版修改；已知正文差异列待办并排除动画，无法定位时保护全部页，其余安全页可直接继续animation。执行失败不能冒作缺环境；环境恢复后重新editable inspect并完成真实预览及审阅。不前台打开Office/WPS。仅修订页面结果预览，不强制渲染全部动画点击状态。

修订执行前保存内部原稿快照，文件差异只允许授权清单；旧动画、媒体、页序及其余属性保持。结果审阅后再进行动画inspect，以当前文件新指纹和真实对象重新绑定，旧字符偏移与旧计划不跨修改复用。PPTX字体交接结果不回写Canva在线设计。

## 3. 轻量动画与交付

动画完整使用《PPT动画轻量规范》《题答动画处理规范》和《动画编排与执行示例》的外部流程。`animation inspect/apply/verify`不依赖主阶段state，不强制全稿预渲染、教学长表单、全部点击状态导出或原生放映。所有处理页完整文字和对象须纳入判断，图片/组合不清、引线归属不清及疑似露答时查看当前源相关图像或可信预览；已有效的修订预览可复用。没有看图不填visual_checked=true。

默认覆盖安全页面、350ms点击淡入、完整块同步；题干先见、答案后出。不支持页从plan.pages排除并回报页码与原因，其余支持页继续；不能把题答角色改为普通内容绕过校验。已有未知时间树默认拒绝，本工具任务可复用，明确重做选页用replace_selected。检查证明内容保真与计划写入，不等于PowerPoint/WPS实播通过。

目录、管理编号、阶段4主题子目录、内部原稿历史归档及唯一当前稿沿用原规则。动画直接更新实际工作PPT，并规范为<主题>_可编辑动画版.pptx，不递增版本、不重名覆盖。动画证据放`_state/工具任务/animation/<task>/`，原稿快照继续放`_state/阶段5/originals/`。不创建用户可见阶段5文件夹，不修改基础交付及其完成事实。修订与动画各自记录输入输出，不能用修订已完成状态冒称动画已执行。

新任务不再使用旧record-animation-plan/apply-teaching-animation；这些命令仅供有真实旧检查记录的历史动画任务恢复，不能作为新动画默认路线。新增动画严格保持外部计划格式，修订清单不塞进动画JSON。

若修订已写入后才缺少结果渲染环境，保留已写入文件及前后快照，记录结果审阅延后；未复核修改页与已知待办页排除动画，其余未改动安全页可继续，环境恢复后重新inspect。

## 接续与恢复边界

同一设计再次修订后，下载及准备按本次文件指纹区分版本；各版下载manifest独立保留。未完成事务先恢复或明确排查，不能将新导出误认成旧事务已完成；发布/恢复前均核对工作名和最终名。下载通过实际包部件、页序及内部关系检查后才允许准备工作文件和归档旧成品。

修订中断恢复先核对当前输入、原稿快照、计划、全部预览/字体/交接及正文依据，并验证候选，再写回。证据失效时不先改当前PPT再报错。已知待办随已验证的动画更名及后续时间树修改保留；未解决页继续排除。缺环境仅延后不能验证的工作，保留已有待办和排除页。任务类型与首次检查状态同时保存，恢复不回退到旧动画流程。doctor对未审阅结果同样核查文件存在性与指纹；只有经过验证的动画接续才使用原修订结果快照复核。

原阶段4主题子目录、文件命名及纯动画免init不变。自动定位包含该主题目录并优先已有有效当前稿，多候选不猜测。跨框字体segments清单及shape_ids交接与单框格式保持互斥，同时通过schema和运行时检查。
