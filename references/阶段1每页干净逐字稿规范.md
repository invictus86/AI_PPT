# 阶段1每页干净逐字稿规范

> 当前1.2.0：三步基础流程见《阶段流程.md》。第一步规划经主控深度审阅可生成四封面，用户选封面并授权试做时才确认规划；第三步实际全稿由主控验收锁定，不新增PDF用户审批。主题活动内容与配套优先遵循《主题班会与家长会深度二创规范.md》《主题活动教案与会议实施方案规范.md》。

## 目标

`阶段1_规划确认/每页干净逐字稿.md` 用来让用户逐页审阅 PPT 内容。它解决的是 `页面规划.md` 表格不适合阅读长文本的问题。

这份文档是“页面可见文字逐字稿”，不是讲者演讲稿。即使用户提前提出讲稿、口播稿或备注稿需求，阶段1也只记录讲者身份、语气、时长、备注偏好等后续阶段3约束，不生成正式演讲逐字稿。

## 权威关系

- `_state/阶段1/content.json` 是唯一文字源。
- `页面规划.md` 是从同一内容派生的用户可见逐页规划表，不是第二份文字权威。
- `每页干净逐字稿.md` 是从同一内容派生出来的用户阅读稿。
- `slide_prompt_briefs.json` 和阶段2 final prompt 必须继承同一批最终可见文字。

如果四者之间出现文字不一致，不能选择其中一个继续向下游推进；必须先按确认意见修正 `content.json`，再同步派生的 `页面规划.md`、`每页干净逐字稿.md` 和 `slide_prompt_briefs.json`。

## 推荐结构

文件开头写清：

```markdown
# 每页干净逐字稿

本文件用于逐页审阅最终可见文字。页面规划、结构化内容和后续图片提示词必须与本文件逐页一致。
```

每页使用统一结构：

```markdown
---

## 第 01 页｜页面标题

**页面角色**：cover
**本页目的**：建立主题和观看预期

### 页面可见文字

# 主标题

副标题或说明句

- 信息项 1
- 信息项 2
```

## 排版规则

- 用 `---` 分隔页面。
- 每页必须有 `第 XX 页｜页面标题`。
- `页面可见文字` 是主体，不要被资料依据、视觉说明或制作备注淹没。
- 长内容按语义拆成短段、要点、编号、表格或流程，不要堆成长句；故事须保留必要叙事关系和转折，不能为分条或简洁压成事件清单。内容太长先取舍或跨页组织，不删支撑理解与结论的关键经过。
- 表格页使用 Markdown 表格，保留表头、行列关系和重点标注。
- 流程页使用编号步骤，保留动作顺序和判断节点。
- 对比页使用左右栏或表格，保留比较维度。
- 数据页用关键数字或结论句先建立阅读锚点，再列解释文字。
- 目录页、模块介绍页、总结页保持简洁，不因逐字稿而加厚；简洁不省略必要解释、认识收束或主题意义。通读同一页组的实际可见文字，检查问题回应、事实到认识及页组接续，不能靠本页目的或教师临时补讲判断完整。

## 页面角色写法

- `cover`：主标题、副标题、机构/汇报人/时间等信息分层写清。
- `agenda`：必设目录页，按实际目录结构呈现短标题及关系，可采用编号、分组、路线或问题链，不写大段解释；条目与正文模块及顺序一致，可见文字与该页 `final_visible_text` 同源。
- `section_divider`：只写模块编号、模块标题和必要短说明。
- `concept` / `definition`：先写定义或结论句，再写 2-4 条解释。
- `process`：按步骤写，动作词前置。
- `comparison`：使用表格或左右对照。
- `data`：关键数字突出，来源如需可见再写入；否则来源只放 `页面规划.md`。
- `table`：使用 Markdown 表格，不压成长串文字。
- `summary`：按实际内容整理关键认识及其依据，可用短段或要点，不设固定条数；提问、排除错误推论、重复目录或安排任务本身不能代替总结。故事/讨论的收束可融入相关页面，不强制每例独立设页。
- `closing`：回应开头的问题，完成本课主题表达，再按需要感悟、联系生活或提出下一步；不只重喊标题、列技能或要求承诺，不强制统一结尾。相关认识须来自前文材料，不能在阅读稿中临时新增升华文字。

## 禁止事项

- 不新增 `content.json` 之外的可见文字；修改正文源后再同步页面规划和干净逐字稿。
- 不把内部资料依据、原PPT/其他课件/教案的引用、来源链接、prompt、视觉意图或内部备注写进 `页面可见文字`。按深度二创规范直接整理讲述案例，不写“原作者”“改编自原稿”等旧稿关联；独立公开报道、作品或机构记录的简要出处如需可见，须先批准写入 `final_visible_text`，不能代替案例的必要介绍。
- 不用 OCR 或阶段2图片识别结果回填逐字稿。
- 不把多页内容合并成一段总稿。
- 不在阶段1生成正式演讲逐字稿、口播稿或备注稿；相关要求只记录为阶段3约束。
- 不用一整张宽表承载所有页面正文。
- 不把“页码”规划索引写成画面可见页码，除非用户明确要求加页码。
