# 通用视觉美学规范

## 目标

本规范定义 PPT Skill v3 所有内容型 PPT 共享的视觉质量底线。它不是风格模板，不指定固定主题、固定配色或固定版式；它约束主控大模型在阶段1规划、阶段2封面候选、阶段2整页图片和阶段2审美 QA 中如何做审美判断。

适用场景包括老师课件、护理宣教、大学答辩、创赛路演、专业汇报、资料改造和仿做升级。

## 核心原则

- 内容优先于装饰。任何视觉元素都必须帮助理解、记忆、比较、行动或说服。
- 每页只承担一个主要传播任务。复杂内容可以拆页，但不能为了好看随意删掉已确认内容。
- 选定封面后，整套 PPT 必须处在同一个视觉世界中。把封面的色彩、字体、媒介、质感和构形语言延展为可承载内容的内页系统，不能只复制封面装饰，也不能一页一套；未选定的四封面候选可以各有独立视觉表达。
- 可见页码默认不显示。只有用户明确要求加页码时，才把页码作为统一视觉家具写入整套 PPT。
- 中文文字必须清晰、准确、可读。图片模型不得新增伪文字、英文占位、拼音、乱码或 lorem ipsum。
- 页面节奏允许变化，但变化应来自页面角色差异，不是随机换风格。
- 图片不是壁纸。主视觉要和页面主题、受众和表达任务有关。
- 教学、护理、答辩、创赛等路线可以有不同气质，但都要保持专业可信。

## 教学型精美

- 先判断内容关系，再选择版式：比较须同维对应，流程须顺着读序，原因与结果须连接明确，示范与练习须能辨认当前步骤。卡片、分栏和插图是表达手段，不是先验骨架。
- 页面形成清晰的主次、稳定版心、功能分区和阅读路径。标题、材料、解释、任务或结论按需要区分层级，不把每个短句都装成独立卡片；内容简单时允许一个核心文本区和充分留白。
- 整套节奏来自页面任务与信息复杂度。同类比较、连续示范或练习可以沿用必要骨架，帮助定位；既不连续堆无差别卡片墙，也不为追求变化打乱可学习的对应关系。
- 优先为核心解释、方法示范、比较判断和练习页分配清晰的阅读空间与图文细节。人物和情绪插画不得挤掉必要材料、操作过程或学生需要处理的信息；不能只把封面和章节页做精美。
- 图像帮助理解当前对象，文本区承接必要说明；说明与对应图形保持邻近，箭头、编号和强调色含义一致。装饰留在次要位置，不与任务指令或关键证据争夺注意力。
- 按既有页面规划、PPT一致性、图片风格和逐页画面计划落实这些选择，不另建一份视觉权威或新增用户验收节点。

## 视觉系统

阶段1 `design_contract.json` 和阶段2 `deck_style.json` 应共同定义以下内容：

- 视觉气质：专业、亲和、学术、稳重、温暖、行动感、科技感等。
- 色彩策略：主色、辅助色、中性色、强调色、背景色和文字色。
- 明度策略：标题、正文、注释、弱化信息之间要有清楚明度阶梯。
- 对比策略：正文和背景必须有足够对比，不用浅灰小字压在复杂图上。
- 字体策略：中文主字体、标题权重、正文权重、数字和单位处理方式。
- 图像语言：摄影、3D、插画、信息图、抽象视觉、真实场景等。
- 视觉家具：页眉、页脚、章节标签、logo、分隔线、角标的统一规则；页码默认关闭，只有用户明确要求时才定义统一规则。
- 节奏策略：哪些页面保持稳定，哪些页面作为章节、案例、总结或关键观点做节奏变化。

## 中文排版

- 标题应能被快速扫读。阶段1可把长标题规划为主标题和副标题，并同步写入本页 `content.json`；正文批准后，风格和生图阶段只能按原文安排字重、间距及语义断行，不能自行增删或改写标题。
- 正文每个层级应有稳定字号、字重、颜色和行距。
- 数字、单位、年份、阈值、医学术语、研究术语和专有名词必须原样保留。
- 多行中文避免过窄文本框和过长单行。必要时按语义换行。
- 不使用图片模型自由生成页码、标签、英文装饰字或伪 UI 文案；用户未要求时不得出现可见页码。
- 如果页面文字量天然较多，应通过分组、对比、流程、表格或拆页解决，不靠压缩字号硬塞。

## 配色与质感

- 不做单一色相堆叠。主色、辅助色、中性色之间要有功能分工。
- 不使用廉价大面积渐变、随机发光、过量阴影、漂浮装饰和无意义背景纹理。
- 医护、教育、学术等内容可以亲和，但不能幼稚或娱乐化。
- 创赛和路演可以更有能量，但不能牺牲事实可信度。
- 仿做升级型应尊重原 PPT 的品牌色、机构色或既有视觉资产；除非用户要求，不彻底换风格。

## 图片与图形

- 图片应承担明确角色：场景建立、概念解释、流程辅助、证据呈现、情绪引导或记忆锚点。
- 不让图片承载复杂小字、伪表格、伪 logo、伪二维码、伪界面。
- 专业场景的图片要可信，避免夸张病理、错误器械、错误护理动作或误导性医学场景。
- 学术和答辩页面优先保留证据、图表、方法、结论之间的关系。
- 课件页面优先服务学习路径，概念、例题、练习、总结应有清晰层级。

## 负面清单

以下问题应触发主控返工判断：

- 中文文字乱码、半字、糊化或模型自造字。
- 出现英文占位、拼音、lorem ipsum 或无意义装饰文字。
- 内容被模型改写、删减、乱加，尤其是数字、单位、专业术语和结论。
- 页面主视觉和主题无关，只是漂亮背景。
- 同一套 PPT 中媒介混乱，例如一页真实摄影、一页卡通、一页 3D，且没有设计理由。
- 连续多页重复卡片墙，没有节奏。
- 为了版式变化破坏同类材料的对应关系，或把简单内容强行切成多个功能空缺的分区。
- 封面精美而核心解释、示范和练习页粗糙，人物或装饰挤掉必要说明。
- 对比不足，正文难读。
- 页面过满、过空、重心失衡或元素重叠。
- 卡片套卡片、装饰套装饰，信息反而更难读。

## 写入下游资产

阶段1：

- `页面规划.md` 写清每页内容、信息关系、阅读顺序和视觉意图；核心解释与练习页说明材料、过程和任务如何获得足够空间。
- `design_contract.json` 写清整体审美、路线、受众、色彩、字体、图像语言、页面角色和封面候选策略。

阶段2A：

- `style_cards/cover_option_A-D.json` 把四种候选风格变成可追溯设计选择。

阶段2B：

- final prompt 必须继承页面文字合同、design contract、deck style、layout intent 和本规范禁止项。

阶段2 QA：

- 主控大模型按本规范做轻量审美 QA，runtime 只记录结构化结论，不自动评分。
