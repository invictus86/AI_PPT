# 题答动画处理规范

页面含提问、练习、病例讨论、观察提示或答案揭示时加载。完整块、默认阅读顺序与执行流程沿用[PPT动画轻量规范](PPT动画轻量规范.md)。新编排使用schema 1.1。

## 1. 先辨认用途，再决定先后

题目必须先于它的推理和答案。解析不统一后置，先看这段是在**帮助推出答案**，还是在**答案已给出后补充验证**：

- 发现错误、提供提示、代入反例、推导结论：题目/必要材料 → 答前推理reasoning → 完整答案answer。
- 先公布答案，再解释或验算：题目/必要材料 → 完整答案answer → 答后解析explanation。
- 两种都存在：题目 → 答前推理 → 完整答案及标记 → 答后解析。没有哪个环节就不新增哪个环节。

“反例”“验算”“解析”等文字不决定角色，位置也不决定角色。主控读完整内容及前后关联页，判断本段对下一步理解的作用；不能将普通标题冒充题干，也不能为了校验通过把真实答案改成content。

例如前页题目“解x²>4”，原作答“x>2”；当前页上方“取x=-3：x²=9>4，原作答漏了负数这一侧”，下方“正确范围：x<-2或x>2”。上方是在帮助发现遗漏，属于reasoning，先出；再出下方完整答案。默认阅读顺序和教学依赖一致。不能沿用旧规则强行先答案后反例。只有实际内容明确是答后的补充验证时，才标explanation。

## 2. 绑定与角色

| role | 呈现合同 |
|---|---|
| question | 真实题目/开放问题，question_id必填；默认首屏，情境先出、问题后问或逐题揭示时可用后续点击 |
| given / options | 同题必要条件、普通选项、原错误作答材料；不得晚于题目，题目出现时必须能完整作答；同题拆成多个question对象也须同步 |
| reasoning | 答前提示、推理或证据；晚于真实题目及必要材料，早于同题完整答案；可以多步，无结论答案的开放材料用content和真实依赖 |
| answer | 原稿完整答案，click>0；同题全部答案成员在同一页同一步出现，不把一个完整答案的多部分伪造成多道题 |
| answer_marker | 独立正确标记，与同题answer同页同步，不能跟普通选项提前出现 |
| explanation | 答后补充解析，严格晚于对应answer，可同页后续点击或后续页 |
| content | 普通标题、正文、共享上下文、开放观察材料/讨论归纳；不能用作掩盖漏判题答的兜底角色 |
| safety / decoration | 必要提醒和公共装饰初始可见；卡片专属图形归完整块，不误作公共装饰 |

题干、条件、答案、理由已经在不可拆文本框/图片/原生组中时按完整对象控制；不可同时满足防露答和先后要求则报告needs_layering，不拆框、解组、加遮罩或修改原文。答案及内嵌理由一体时可作为完整答案同步，不为了细分角色破坏原对象。单张必要图片烘焙了答案也不能用整图淡入冒充先题后答。

答页复述已知背景、分类讨论的分支标签不自动当成原题given；结合原题确认它是原始条件、答前推理，还是当前页组织上下文，避免把后页标签误要求提前到题目页。

同块正文、局部标题、编号、图标、专属图片/底板/引线优先放一个unit；需要区分角色的同步成员用binding_id，程序检查同步。图文没有教学依赖时按完整块的上到下、同排左到右基准；有教学依赖时由依赖覆盖基准。绑定与严格先后冲突先核对误绑/误标，不能随意解除正确绑定。

不新增、推导、纠正或改写用户PPT的答案；这里的“推理”指编排原来已经存在的内容。开放问题保持开放，不把提示伪装标准答案。纯练习、写作、互评或比较任务需要完整可读且没有独立后出内容时可首屏全显，写清static_reason，不用动画拆掉作答条件。

## 3. 同页、多题与跨页

| 组织 | 顺序 |
|---|---|
| 同页单题 | 题目与材料默认S0；按当前内容选择答前推理→答案，或答案→答后解析 |
| 同页多题 | 可全题先见后逐题回答，也可题1→答1→题2→答2；每题材料完整，每个题号独立匹配，已显示内容保留 |
| 情境后提问 | 情境先可读，真实question后续点击呈现；必要条件/选项最迟同一步，答案或提示再等新点击 |
| 前页题目，后页推理/答案 | 题目先完整呈现；后页按推理与答案的真实依赖展开，不复制题干 |
| 跨三页及以上 | 按真实页序核对题目、推理、答案、答后解析；数组重排不能改变幻灯片页序 |

跨页使用顶层question_refs绑定同一源指纹下的真实题目页和原对象，不凭模糊“前面讲过”连接。每项包含question_id、slide_index、targets、evidence；题目页含图片/图形时检查当前材料后填visual_checked:true。题号、公式、案例、条件或明确承接关系是配对依据，不能只凭相同版式。

例：`{"question_id":"Q18","slide_index":18,"targets":[12,13,16,19],"evidence":"第18页解x²>4及x>2错解；第19页先用-3发现遗漏，再给完整范围","visual_checked":true}`。真实ID从当前inventory取。

题目页可以不在本次apply选页中，执行器只读核对页码/对象，主控须确认其实际题目与必要材料在进入答案页前已呈现；不修改或复制题干。若题目页也被选中，引用须包含真实question，所引用成员只能为同题question/given/options，不含普通标题。schema 1.1允许真实题目后续点击，仍检查其与材料、推理、答案的先后；旧schema 1.0的click=0限制只用于历史任务恢复。

默认question_id保持同页作用域；只有question_refs显式连接跨页，避免各页Q1被误合并。将推理、答案与解析页纳入同一计划，不能凭空假定未声明的答案节点已呈现。主标题含答案仍按answer并与同题答案同步，写title_exception_reason说明先观察再揭题；标题先见规则不能覆盖防露答。

当前是350ms人工点击淡入、累计显示。支持独立完整块的多步推理，不支持一段不可拆文字内部逐字推导、自动延迟、退出上一题或退页自动重置。

## 4. 重点复核与验证边界

1. 先确认真实题目与必要材料，再匹配答案、正确标记、推理及解析。角色不明时回看整页及关联页，仍不明则列具体对象和限制，不随机标记。
2. 查静态标题、图片、图例、背景、旁注和页底结论是否提前给出结果。图表/证据本身不自动等于答案；疑似泄答时查看当前源图，不能只查XML文字。
3. 查同题完整答案及标记同步；推导答案的反例先于答案；答后说明后于答案；不同题号不交叉串联；跨页按真实页序。
4. 查整卡、图文、局部底板/引线一起出现，共享对象只分配一次；默认阅读顺序被改变时有具体版式或教学依据。
5. 程序在写入前和结果文件复核绑定、顺序、时间树及非动画内容保护，并输出block_ordering。它不能证明角色和依据真实；主控内容审阅仍须进行。旧schema 1.0报告legacy_not_checked，不能冒称已通过新排序检查。

完整声明及调用见[执行示例](动画编排与执行示例.md)，字段见[schema](../scripts/schemas/animation_plan.schema.json)。首屏检查、快照、原位写回保持；新规则不新增用户确认节点，不把后台状态图或文件校验冒称原生播放器放映通过。
