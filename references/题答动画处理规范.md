# 题答动画处理规范

页面含提问、练习、病例讨论、观察提示或答案揭示时加载。完整块和执行流程沿用[PPT动画轻量规范](PPT动画轻量规范.md)，本规范负责真实题答识别、同页及跨页顺序。

## 1. 先认清整组页面的教学任务

完整顺序是**题目先呈现→对应答案随后出现→独立解析再出现**。题目、答案和解析可同页，也可分布在连续或明确关联的多个页面；不要求答案页重复题目。普通标题按标题处理，不能把“把粗心改成可检查的记录”等标题冒充题干来满足校验。角色由主控读完整内容及必要图像后判断，不按问号、字号或位置推断。

| 内容 | 默认安排 |
|---|---|
| 真实题干、必要条件、普通选项、作答要求 | 所在题目页S0先见并保留，可以与主标题同首屏 |
| 原错误作答 | 明确为辨析材料时先见，不误当成正确答案 |
| 正确答案与正确标记 | 等待新人工点击；同题全部答案成员同次出现 |
| 独立解析、反例、验算 | 对应答案之后的点击或后续解析页，不按版面上下决定顺序 |
| 开放观察提示或讨论归纳 | 有原稿内容时在思考/讨论后揭示，不称新增标准答案 |

不补写、推导或纠正用户答案。题干或答案本身已有内嵌理由时保持完整对象，不为分开播放拆框。没有答案的开放题保持开放，不创作答案来凑动画。

## 2. 同页与跨页的支持方式

| 组织 | 顺序 |
|---|---|
| 同页单题 | S0题目及必要材料；点击1完整答案及标记；点击2独立解析，无解析不加该步 |
| 同页多题 | 全部题干、条件和普通选项S0；各题答案分别点击，独立解析在对应答案后 |
| 前页题目，后页答案与解析 | 前页完整出题；后页主标题默认先见，点击答案、再点击解析；无需复制题目 |
| 三页分别呈现题目、答案、解析 | 题目页先于答案页，解析页再后；分别按当前页完整块安排，不要求跨页保留前页题干 |
| 前页原错误作答，后页订正与反例 | 错题材料先见；后页正确答案→反例/验算，正常且可保留 |

例如第18页“解x²>4；原错误作答x>2”，第19页“正确范围x<-2或x>2”点击1，“取x=-3，9>4，原作答漏负数侧”点击2，是有效跨页顺序；不能因第19页没有原题、或反例位于版面上方而判错。

题1→答1→再出题2→答2、同题多级提示后出答案、答案分步推导仍不是当前执行模式；不通过改成content或伪造多题号绕过。当前累计显示，不承诺点击切题、隐藏上题、退页自动重置或自动延迟答案。

## 3. 关联依据及防止提前露答

1. 先确认真实题目在哪页、对应哪些原对象，再按题号、公式、案例、条件或明确承接关系建立配对；不能用模糊“前面讲过”作证。题答不匹配或关系不能确认时报告具体页码、对象及缺口。
2. 核对正确答案、勾/星号/选中框、标题、旁注、图例和页底结论是否提前给出结果。标题含答案时可例外后出，记录当前页理由，不为标题先见而泄答。
3. 图片、组和背景不清或疑似含题答时看当前源相关图像/可信预览；必要证据不等于答案，不把所有图表隐藏。对跨页题目及答案页都复核，不因XML无文字就认定没有泄答。
4. 正确标记与普通选项不可分、题答同框/同组、答案烘焙在必要背景等情况，报告需要分层，不拆框、解组、改色、重绘或加遮罩，不把整题隐藏或答案全显当完成。
5. 核对真实题目已先于答案、同题答案同步、独立解析后继，以及静态组是否露答。纯文件检查不能证明角色判断和关联依据正确；主控实际审阅仍负责语义。

## 4. 紧凑plan的关系声明

| role | 合同 |
|---|---|
| question | 真实题干，question_id必填，click=0；不是普通标题 |
| given / options | 对应题目的条件、普通选项或原错误作答材料，click=0 |
| answer | 完整原稿答案或单次观察提示，click>0，同题全部answer同一页同一步 |
| answer_marker | 同题独立正确标记，与answer同页同步 |
| explanation | 原稿独立解析，排在对应answer之后；可同页后续点击或后续页 |
| content | 普通标题、正文、共享上下文；不能兜底掩盖漏判的题答 |
| safety / decoration | 必要提醒和公共装饰，click=0；局部专属成员仍归完整内容块 |

默认question_id保持同页作用域，避免旧计划不同页各用Q1时错误合并。跨页题答必须显式增加顶层`question_refs`数组，每项包含：`question_id`、真实题目页`slide_index`、原顶层对象`targets`、具体匹配`evidence`；题目页含图片/图形时查看其材料后填`visual_checked:true`。引用与整个plan共同绑定同一源文件指纹，不接受别稿对象。

例：`{"question_id":"Q18","slide_index":18,"targets":[12,13,16,19],"evidence":"第18页x²>4及x>2错解；第19页订正范围并用-3验算","visual_checked":true}`。真实IDs从当前inventory取，示例不能直接用于文件。

引用题目页可以不在本次apply选页中，执行器只读核对页码/对象，不修改或复制题干；若题目页也被选中，引用必须包含真实question，并且所引用成员只能是同题question/given/options初始单元，不能引用主标题冒充。显式引用使同题号跨页连接，答案在题目页之后或同页后续点击，独立解析按实际页序及click排在答案之后，plan数组顺序不能颠倒真实页序。三页分布时，将答案和解析页纳入同一计划以核对真实答案节点；无对应答案节点不凭空假定其已呈现。

主标题用现有content角色加`is_title:true`，正文单元用`title_id`绑定。含答案的主标题仍为answer，可填`title_exception_reason`说明后揭依据，并遵守同题同步。具体字段见[schema](../scripts/schemas/animation_plan.schema.json)；完整调用见[执行示例](动画编排与执行示例.md#e1-主标题先见与跨页题答)。

当前没有hint角色：只有一个观察提示揭示节点时，可用answer作为执行锚点，unit.id及备注注明“观察提示”，不冒称标准答案；已有真实答案又要多级提示时沿用能力限制。所有对象只归属一次；完整块成员同步。不能把第二题或真实答案改content以绕过检查。

## 5. 验证边界

程序检查显式引用的源指纹、真实页序、对象存在、已声明角色、答案同步、解析后继、主标题与对应正文顺序；不能靠关键词判断题答语义、证明关联依据真实或自动发现所有伪装角色。主控核对完整文字与必要图像，验证报告保留`controller_review_required`。首屏、覆盖、具体静态例外、内容保护、快照及原位写回沿用主规范；不新增用户确认节点或全稿逐点击渲染。
