# 文档后台全页验收

阶段3保留原Markdown、Word和PDF生成及内容审阅。新增真实排版证据作为内部质量检查，不新增用户审批；不改变用户手动PDF转可编辑PPTX边界。

```bash
python .skill/scripts/pptctl.py render-document-background --input <实际DOCX或PDF绝对路径> --output-dir <项目_state内来源指纹目录>
python .skill/scripts/pptctl.py record-document-layout-review --run-dir <项目> --review <审阅JSON>
```

DOCX由Windows/Microsoft Word隐藏、只读打开，禁止可见窗口、激活、放映或前台回退；重新分页后后台导出PDF，全页由现有pdftoppm渲染。Word存在共享可见文稿时阻断该后台操作，不占用用户前台；依赖缺失则记录并跳过对应验证，不修改用户软件。WPS别名和其他转换器不作为自动备用；独立生成PDF不能证明DOCX真实分页。

PDF直接用现有pdftoppm全页渲染。两种产物都需逐页文字、字体、表格/分页/遮挡审阅；任何页缺失、失败或输入/manifest/图片/渲染环境变化，旧证据失效。源文件只读，过程产物在_state；render本身不生成pass。缓存只有当前来源/环境和全页证据仍有效时复用。

审阅JSON合同：

```json
{
  "method":"background_document_pages",
  "controller_reviewed":true,
  "manifest":"_state/阶段3/document_previews/<来源SHA>/document_manifest.json",
  "manifest_sha256":"sha256:实际manifest指纹",
  "input_sha256":"sha256:实际源文档指纹",
  "unresolved_issues":[],
  "pages":[{
    "page":1,
    "pass":true,
    "image_sha256":"sha256:实际页面图片指纹",
    "text_observation":"写实际文字、中文和段落检查",
    "font_observation":"写实际字形、粗细与可读性观察",
    "layout_observation":"写实际分页、表格、断行、遮挡检查"
  }]
}
```

pages必须恰好覆盖所有实际渲染页；示例不能直接当实际观察填写。源文件及manifest必须属于当前项目；图片和Word派生PDF指纹同样核验。内部审阅按源SHA保存到_state/document_reviews。record-content-review --scope package及后续收口都会核验逐字稿、教案/方案的所有DOCX和PDF有效布局记录；环境具备时没有实际排版审阅不能报告排版验收通过；缺环境按下列规则跳过对应检查，允许其他制作/交付继续，摘要必须列明未验证。正文与深度内容审阅仍分别保持。

## 缺环境的明确例外

`verification-capabilities`只读探测Windows、实际Microsoft Word/PowerPoint、后台PowerShell和pdftoppm，不启动应用。DOCX或PDF缺少对应环境时，render返回`method=verification_skipped`、`status=skipped_no_environment`、`verified=false`、缺项与真实文件SHA，不生成页面或pass。package收口保存对应缺环境记录，阶段4摘要列出`verification_skipped`。正文内容审阅、文件结构和其余已有环境检查保留。

已有环境必须全页检查；执行超时、权限冲突、导出缺页、损坏或已记录的排版问题仍是失败，不能覆盖成缺环境。环境恢复或文件变化后旧跳过记录失效，重新render和审阅；不能编造观察、自动安装软件或切到前台/WPS别名。
